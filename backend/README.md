# Backend Development

This section contains my backend development learning path, with **Java and Spring Boot** as the primary stack.

Backend development focuses on the server-side logic of an application: receiving requests, applying business rules, working with data, handling errors, and returning reliable responses to clients.

## Learning Objectives

- Strengthen Java programming fundamentals.
- Understand HTTP, REST APIs, JSON, and client-server communication.
- Build backend applications with Spring Boot.
- Store and retrieve data using SQL databases.
- Practice validation, error handling, and testing.
- Learn the fundamentals of application security and deployment.

## Learning Path

1. **Java foundations** — classes, objects, collections, exceptions, and object-oriented programming.
2. **Web foundations** — HTTP methods, status codes, JSON, and REST concepts.
3. **Spring Boot fundamentals** — project setup, dependency injection, controllers, and configuration.
4. **Persistence** — SQL, relational database design, and Spring Data JPA.
5. **API quality** — validation, exception handling, logging, and tests.
6. **Security and deployment basics** — authentication concepts, configuration, and deployment preparation.
