# Software Journey

A structured, project-based record of my journey in software development. This repository organizes learning notes, practice exercises, and projects as I build practical skills step by step.

## Learning Tracks

| Track | Focus |
|---|---|
| [Backend Development](backend/README.md) | Java, Spring Boot, REST APIs, databases, and backend fundamentals |
| [Frontend Development](frontend/README.md) | React, component-based interfaces, and frontend projects |

## Goals

- Learn concepts by applying them in practical projects.
- Keep notes, exercises, and projects organized by topic and difficulty.
- Track progress and improve projects over time.
- Build a portfolio that demonstrates consistent learning and problem-solving.

## How to Use This Repository

1. Choose a learning track.
2. Read the README in that folder to understand its purpose and goals.
3. Practice the concepts and add exercises or projects to the relevant directory.
4. Document each project with its purpose, features, setup instructions, and lessons learned.
5. Update progress honestly as work is completed.
