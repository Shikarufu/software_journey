# React — Beginner Level

This stage builds the foundation for creating interfaces with React. Focus on understanding how components work before moving to larger applications.

## Topics to Practice

- What React is and when to use it
- JSX and rendering elements
- Functional components
- Props and passing data
- State with `useState`
- Handling events
- Conditional rendering
- Rendering lists and using keys
- Basic forms and controlled inputs
- Breaking a UI into small components

## Practice Ideas

Start with small exercises such as a counter, profile card, simple task list, or form with basic validation. These are suggested exercises; add them as you implement them.

## Project

The `project_beginner/` directory is reserved for a beginner-level React project that combines the fundamentals above.

## Completion Checklist

- [ ] I can explain JSX and functional components.
- [ ] I can pass data through props.
- [ ] I can update state in response to user actions.
- [ ] I can render lists and handle conditional UI.
- [ ] I can create a simple form.
- [ ] I can run and explain my project.

## Next Step

Move to the intermediate stage when you can build a small interface independently and explain how its components and state work.
