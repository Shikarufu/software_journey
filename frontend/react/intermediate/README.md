# React — Intermediate Level

This stage focuses on building more complete React applications. The emphasis is on managing asynchronous data, separating responsibilities, and creating interfaces that remain understandable as they grow.

## Topics to Practice

- Effects with `useEffect` and appropriate dependency handling
- Fetching data from an API
- Loading, success, empty, and error states
- Controlled forms and validation
- Reusable components and custom hooks
- Routing concepts and page organization
- State sharing between components
- Environment configuration for public frontend settings
- Basic component testing and accessibility

## Practice Ideas

Build a searchable list, a weather interface using a suitable API, a multi-page catalog, or a dashboard that displays remote data. These are ideas, not completed projects.

## Project

Use `project_intermediate/` for a project that combines several intermediate concepts.

## Completion Checklist

- [ ] I can fetch and display data from an API.
- [ ] I handle loading and error states.
- [ ] I can organize an application into reusable components.
- [ ] I understand when an effect is needed.
- [ ] I can manage forms and validate user input.
- [ ] I have documented how to run and test the project.

## Next Step

Move to the advanced stage when you can build a multi-feature application and explain its data flow and component structure.
