# React Learning Path

This directory contains my React learning path, organized by difficulty and project size. The goal is to learn by building interfaces and gradually applying more advanced concepts.

## Roadmap

- **Beginner:** JSX, components, props, state, events, lists, conditional rendering, and forms.
- **Intermediate:** effects, API requests, reusable components, routing concepts, and more structured state.
- **Advanced:** application architecture, performance awareness, testing, accessibility, and robust data flows.
- **Final project:** combine the skills learned into a complete, documented application.

## Recommended Workflow

1. Learn one concept at a time.
2. Make a small example that demonstrates it.
3. Use the concept in a project feature.
4. Test the interface with valid and invalid input.
5. Refactor after you understand the behavior.
6. Update the relevant README with setup instructions and progress.

## Before Starting

Make sure you are comfortable with basic HTML, CSS, and JavaScript. React becomes easier to understand when you already know variables, functions, arrays, objects, and modern JavaScript syntax.

## Project Standards

Every project should have a clear purpose, meaningful component names, readable code, run instructions, and a short explanation of what I learned. Add screenshots or a demo link when available.
